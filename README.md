# Muse 核心设计全解

一个静态单页网站：把 Meta Muse 的 19 个章节逐项拆开讲原理——整体架构、运维、LLM 设计、上下文工程、Agent 循环、审批与认证（HITL）、子代理编排、Skills、连接器、文件架构、定时与后台、安全、数据与隐私、页面交互与多端、Memory、身份与对齐、Feed、Goals 与 Ideas。

- 形式：单个 `index.html`，无构建、无依赖，浏览器直接打开即可
- 风格：深色科技风；多图讲解；含 4 个可交互演示（Agent 循环模拟、审批事件时间线、子代理扇出、上下文组装）
- 口径：文字精简、大白话；每章标注证据等级（实测 / 官方文档明文 / 合理推断），未公开的内部实现不作定论

## 在线访问（GitHub Pages）

仓库 Settings → Pages → Source 选择 `main` 分支根目录后，即可通过 `https://<用户名>.github.io/muse-design-site/` 访问。
