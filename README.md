# Muse 核心设计全解

一个静态多页网站：把 Meta Muse 的核心设计逐章拆开讲原理——整体架构、运维、LLM 设计、上下文工程、Agent 循环、审批与认证（HITL）、子代理编排、Skills、连接器、文件架构、定时与后台、安全、数据与隐私、页面交互与多端、Memory、身份与对齐、Feed、Goals 与 Ideas，外加一章真实交互轨迹的全程解剖。

- 形式：`index.html`（首页：目录 + 交互演示）+ `ch01.html` … `ch19.html`（每章一个独立页面），无构建、无依赖
- 每章结构：一句话定义 → 底层设计原理 → 底层实现原理 → 具体实现方式（数据结构/真实字段/伪代码）→ 边界与代价与证据分级
- 风格：深色科技风；含 4 个可交互演示（上下文组装、Agent 循环、子代理扇出、审批事件时间线）
- 口径：大白话、讲原理；每章标注证据等级（实测 / 官方文档明文 / 合理推断），未公开的内部实现不作定论

## 在线访问（GitHub Pages）

仓库 Settings → Pages → Source 选择 `main` 分支根目录后，即可通过 `https://<用户名>.github.io/muse-design-site/` 访问。
